# 时界安装与 ColorOS 配置

时界是完全离线的个人侧载应用。它不申请联网权限，没有账号、广告或云同步。普通安装只能在打开被限制的应用后把它退回桌面并挡住，不能在系统层禁止启动，也不能阻止你关闭无障碍、强行停止或卸载。

## 安装

1. 把 `dist/时界-release.apk` 拷到手机。
2. 在文件管理器里打开它。若系统拦截未知来源，到该来源应用的设置里允许安装未知应用。
3. 安装完成后先不要强制停止。按下面的顺序打开权限。

安装包的 SHA-256：

```text
2c595174bdc269ef444c783823e566910f425ccbc7e527867a857ceb94a122b3
```

同目录的 `时界-release.apk.sha256` 里也有这一行。安装前可在电脑上对照：

```text
Get-FileHash .\时界-release.apk -Algorithm SHA256
```

## 首次打开

引导页会依次说明：

1. 隐私：数据只留在手机上，默认保存 30 天，系统云备份已关闭。
2. 使用情况访问：用于统计，并在服务重连后按系统记录校正。
3. 无障碍：只在窗口切换时读取前台应用包名，不读屏幕文字、输入内容或控件树。
4. 通知：可选。只有权限被关掉时才发一条低优先级提醒。
5. 后台：ColorOS 上要允许完全后台运行、自启动，并锁定最近任务。

最后一页需要勾选“关闭无障碍、强行停止或卸载后，限制会失效”，才能开始使用。

## ColorOS 16（Find X8 Ultra / Android 16）

设置里可以打开“ColorOS / 后台引导”。每个按钮都会先检查目标页面是否存在。OPPO 私有入口打不开时，会退回系统设置或应用详情，再按下面的文字路径操作。

1. 无障碍：设置 → 辅助功能 → 已下载的服务 → 时界 → 打开。
2. 使用情况访问：设置 → 应用 → 特殊应用权限 → 使用情况访问 → 时界 → 允许。
3. 后台耗电：设置 → 电池 → 应用耗电管理 → 时界 → 允许完全后台行为。不要选“禁止后台运行”。
4. 自启动：设置 → 应用 → 自启动管理 → 打开时界。
5. 最近任务：打开最近任务，找到时界卡片，下滑或打开菜单后锁定。清理最近任务时不要把它划掉。

然后在时界的设置页看“最近一次前台事件”。点“一键拦截测试”，应回到桌面并看到拦截说明。点“我知道了”后可以继续使用其他应用。

退出超级省电后，重新检查无障碍和使用情况访问。系统回收这两项权限后，时界无法继续限制。

## 怎么用

- 今日：保护是否开启、今日总时长、每组剩余额度、下一禁用时段。
- 分组：一个应用只能属于一个组。电话、桌面、系统界面、设置、安装器和时界本身不能加入。
- 每组可以设置生效日期、每天 / 法定工作日 / 自定义星期、多个禁用时段。时段可跨午夜，重叠的会合并。
- 禁用时段之外，全组共享一个每日额度。额度在手机本地午夜清零，不结转到第二天。
- 法定工作日已内置中国大陆 2025 与 2026 年的放假和调休，可在设置里按天修正。没覆盖的年份按周一到周五计算，并显示提示。
- 规则顺序：安全应用 → 应急放行 → 禁用时段 → 每日额度 → 允许。
- 应急放行：当前被拦截的应用，每组每天一次。要写非空理由，并在拦截页等待 30 秒，然后只放行这个应用 5 分钟。放行期间仍计入额度。重启手机会立刻取消。记录保留 30 天。

## 建议自己核对的真机项目

电脑上的单元测试不能代替 Find X8 Ultra。装好后建议看这几项：

- 打开被限制的应用后，大约 1 秒内回到桌面，并显示正确原因。
- 应用一直停在前台时，禁用开始或额度用尽后大约 1 秒内退出。
- 法定休息日不执行“仅法定工作日”规则；周末调班日会执行。
- 今日统计和系统使用情况的当日误差不超过 60 秒。
- 重启、清理最近任务后，只要无障碍仍开着，保护会自动恢复。
- 锁屏时不会靠常驻轮询耗电；重新亮屏后会再判断一次。

## 升级签名

后续升级必须用同一把密钥，否则系统会拒绝覆盖安装。

- 密钥文件：`keystore/shijie-release.jks`
- 别名：`shijie`
- 库密码和密钥密码写在本机的 `keystore/credentials.local.txt`，该文件不要提交，也不要发给别人。

## 重新构建

开发依赖可以联网下载。应用运行时不联网。

本机已使用 `127.0.0.1:7890` 代理，Maven 优先走阿里云镜像。配置写在项目的 `gradle.properties`。代理没开时，阿里云镜像仍可直接访问。

```text
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build-release.ps1
```

构建环境放在 `work/`：JDK 17、Android SDK 36。要求 `minSdk 29`，`compileSdk` / `targetSdk 36`。
